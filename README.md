I created this project in my statistics computer science class where we learned advanced statistics and coded Java projects that related to the concepts! 
This was a learning experience for me since it helped me learn how to implement different Java libraries and use MATLAB for the first time. 

There are written reports alongside the code - you can find them in the "Plotter Salter Smoother reports" folder. 

The purpose of this project? To perform the same task three times and find a more efficient way to do it. Those being Java libraries and MATLAB. 

First, I coded a Java program that wrote mathematical data from equations to a .csv file to plot it and then read it in order to salt and smooth it. (These graphs were plotted)
Second, I coded a Java program that used Jfreecharts to code the same thing but this time in a more efficient way. 
Third, I learned MATLAB syntax and created the graphs using simple commands in the program. 

All of the parts of the project are in their determined folder. For example, you will find all .java files and .m files.
